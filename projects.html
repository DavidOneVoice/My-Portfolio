01 / School managementIn development

GradeVault

Student records, academic workflows and reporting in one application.

  • React
  • Vite
  • Material UI
  • Express
  • MongoDB
  • Cloudinary

2025 — Present

What it does

GradeVault organises school work around academic sessions and terms. Administrators, teachers and students have different screens and responsibilities, while records remain connected across classes, assessments and reports.

  • Student and class records, teacher assignments, academic sessions and terms.
  • Score entry, averages, rankings, comments and printable student reports, with previous term results available in archives.
  • Daily class attendance and term summaries.
  • Teacher-authored assessments, an approval workflow, timed student submissions and multiple-choice grading.
  • Timetable generation using teaching workloads and availability, with conflict checks and reporting for sessions that could not be placed.

My role

I came up with the project and built the entire frontend. A collaborator contributed to the product design, and another contributed to the initial backend. I later took on backend development and plugins as well, using AI assistance during implementation.

How the application fits together

The React frontend uses Material UI for interface components and connects to an Express API. MongoDB holds school and academic records. The interface changes by user role and the selected academic session and term.

GradeVault is still in development and has not been publicly deployed. The source repository is private.

OVTech Academy

Applications, course delivery and certificates for a technical training academy.

  • React
  • Vite
  • Firebase / Firestore
  • Cloudinary
  • EmailJS
Visit website ↗View source ↗

What it does

The platform supports the learner journey from a scholarship application through enrolment, lessons and course completion. It also provides administrative tools for managing that work.

  • Scholarship applications, application review and enrolment administration.
  • Student dashboards for self-paced and instructor-led courses, with lesson videos, resources, progress tracking and scheduled content release.
  • Live-session administration and attendance records.
  • Certificate profile review, PDF certificate generation, public verification and certificate revocation.
  • Curriculum imports from spreadsheets and an optional alumni directory.

My role

I built the React application and Firebase workflows, covering both learner screens and administrative tools. I also maintain the platform and handle deployment and production fixes through my work at OVTech.

From learning content to a usable course

The work includes connecting curriculum content to lessons, recording progress, deciding when content becomes available and carrying course completion into the certificate workflow. Firestore stores the platform’s application, course and learner records.
